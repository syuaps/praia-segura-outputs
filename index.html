Praia Segura - Publicação de arquivos (GitHub Pages)

Este site serve como "servidor" estático para o aplicativo. O GitHub Pages não lista pastas automaticamente; por isso este index.html funciona como menu.

Base URL para o app: https://syuaps.github.io/praia-segura-outputs/

Atalho rodada_atual.json - carimbo da última atualização

Se o link acima abrir, o Pages está servindo corretamente os arquivos.

Previsão - outputs/
  • outputs/forecast_full.json (agregador principal da rodada)
  • outputs/products/ifs_oper__recife.json (ECMWF Open Data - IFS HRES operacional)
  • outputs/products/ifs_ens_probs__recife.json (ECMWF Open Data - probabilidades do ensemble)
  • outputs/products/TPXO10_atlas_v2_recife.json (marés TPXO10 atlas v2)
  • outputs/products/cmems_mod_glo_phy_anfc_merged-sl_PT1H-i__recife_timeseries.json (Copernicus Marine - série temporal em Recife)

Fluxo recomendado no app: rodada_atual.json → outputs/forecast_full.json → produtos específicos em outputs/products/.
